
# :trophy: mi-ecommerce-custom
este es un ecommerce de prueba...

## 🚀 Configuracion/Ejecución:

para poder ejecutar el proyecto localmente:

```bash
git clone https://github.com/fuzzntrp3900/mi-ecommerce-custom.git
```

intalacion de dependencias (node_modules):

```bash
#instala la carpeta node_modules para correr el proyecto
npm install
```

finalmente ejecutarlo:

```bash
#abre el enlace local del proyecto en el navegador
npm start 
```

## 🏗️ Componentes Implementados:

- __CartWidget:__ Representa el icono de carrito de compras y contador.
- __Navbar:__ Barra de navegacion que contiene logo, categorias y el Cartwidget.
- __ItemListContainer:__ Representa el contenedor principal que muestra listado de productos.
- __Item:__ Es la plantilla que representa un producto del e-commerce.
